About this workspace

Reconcile matches stable business keys, isolates duplicates, and compares field values using explicit rules.

Exception counts represent findings; one record may have multiple findings. Matching records are unique pairs with no value exceptions. Schema findings apply to the entire dataset.

Review decisions preserve the original evidence. Run a new comparison after applying a correction to verify it worked.

CSV files use UTF-8. Date tolerances are in days; numeric tolerances are absolute. Blank values are nullable unless a rule says otherwise.

This deployment supports one application process and a persistent local data volume. See the supplied operations guide for production configuration.
